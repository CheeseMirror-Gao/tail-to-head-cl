# CIFAR-100 Tail-to-Head 两阶段实验记录

## 实验设置

- **数据划分**。CIFAR-100 的 100 类按种子 `1993` 分成 50 个头部类和 50 个目标类。第一阶段，`k=0` 使用 25,000 张头部类图。`k=5` 使用同一批头部类图，再加入每个目标类的 5 张图，共 25,250 张。
- **第二阶段**。两组共用每个目标类的 300 张新图，共 15,000 张。第一、二阶段的训练图片索引互不重叠，第二阶段只用这些新图更新模型。
- **训练**。使用 PyCIL 的 ResNet32 和 100 类分类层，图片用 `ToTensor()` 转换。两阶段都用 SGD，学习率为 `0.001`，批大小为 128。第一阶段训练 5 轮，第二阶段训练 1 轮（118 批）。
- **训练种子**。主对照在第一阶段创建模型前设置 `torch.manual_seed(1993)`，第二阶段用独立的 `torch.Generator` 和种子 `1993`，让两组按相同顺序读取第二阶段图片。
- **评估**。使用 CIFAR-100 官方测试集，头部类和目标类各 5,000 张。每张图都从 100 个类别中取分数最高的一个。第二阶段第 0 轮指加载第一阶段权重后、开始更新前。

## 固定训练种子后的对照

| 第一阶段每个目标类的样本数 | 第二阶段轮次 | 头部类 Top-1 准确率 | 目标类 Top-1 准确率 |
|---|---:|---:|---:|
| `k=0` | 0 | 8.36% | 0.00% |
| `k=0` | 1 | 4.70% | 1.86% |
| `k=5` | 0 | 7.80% | 0.00% |
| `k=5` | 1 | 4.34% | 1.74% |

- **目标类准确率差**。在第二阶段完成相同的 118 次更新后，`k=5` 比 `k=0` 低 0.12 个百分点（87 张对 93 张）。
- **头部类准确率下降**。分别用各组第 0 轮减去第 1 轮的准确率，`k=0` 下降 3.66 个百分点，`k=5` 下降 3.46 个百分点。
- **权重核对**。第一阶段保存前与第二阶段加载后的头部类准确率一致，分别为 `k=0` 的 8.36% 和 `k=5` 的 7.80%。

以上结果来自一个训练种子和第二阶段一轮训练。要判断提前接触少量目标类图片的影响，需要比较多个种子以及更多相同训练步数下的表现。

旧版第二阶段脚本曾把评估数据设为 `train=True`。上表的 `k=0` 采用改为 `train=False` 后在官方测试集上的复测结果。

## 运行记录

用 `make_tail_to_head_split.py` 生成 `cifar100_tail_to_head_split.npz`。服务器上的两阶段脚本按以下命令运行。

```bash
python run_tail_to_head.py --k 0 && python run_tail_to_head_stage2.py --k 0
python run_tail_to_head.py --k 5 && python run_tail_to_head_stage2.py --k 5
```

固定训练种子后的两个第一阶段权重分别保存为 `tail_to_head_k0_stage1_seed1993.pt` 和 `tail_to_head_k5_stage1_seed1993.pt`。
